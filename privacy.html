隐私政策

最后更新：2026-09-28 ｜ 联系邮箱：me@nickyam.com

本政策说明您在使用涯木云（yun.nickyam.com）时，我们如何收集、使用、存储与保护您的信息。上传或使用即表示您已阅读并理解本政策。

一、我们收集的信息

  1. 您主动上传的内容：您上传的图片 / 文件本身，以及文件大小、格式、上传时间等元数据。
  2. 访问与日志信息：您的访问 IP 地址、请求时间、浏览器类型（User-Agent）、来源页面（Referer）及访问记录，用于安全风控（防盗链、限速、内容审核）与服务运维。
  3. 登录凭证：上传与管理后台的账号密码仅保存在您本机浏览器的 localStorage 中，不会上传到服务器，清除浏览器数据后即失效。
  4. 联系信息：您主动通过邮箱联系我们时提供的姓名与内容。

二、信息如何使用

  1. 提供、维护与改进存储与分享服务；
  2. 识别与拦截盗链、盗刷、违规内容与恶意请求，保障服务安全；
  3. 依据法律法规或有权机关要求配合核查；
  4. 不将您的个人信息用于与上述目的无关的用途，亦不出售给任何第三方。

三、信息的存储与第三方

  1. 本站运行于 Cloudflare Pages 网络之上，您的请求会经由 Cloudflare 的边缘节点分发与缓存；相关数据处理遵循 Cloudflare 的隐私政策。
  2. 上传的文件与元数据存于本站指定的存储后端（如消息机器人 API / 对象存储 / KV），并由该后端按其策略保管。
  3. 在您文件涉嫌违法违规、或应有权机关合法要求时，我们可能向相关方披露必要信息，且不承担因此产生的责任。

四、Cookie 与本地存储

除登录态存于您本机 localStorage 外，本站不设置用于广告或跨站追踪的 Cookie。清除浏览器数据会让您退出登录，需重新输入密码。

五、保留期限

  1. 文件不承诺永久保存，可能因清理、迁移、故障或策略调整被删除或无法访问，您应自行在本地备份原文件。
  2. 访问日志仅在实现本政策所述安全与运维目的所需的合理期限内保留，之后定期清理。

六、您的权利

  1. 您可随时删除自己上传的文件；如需协助删除或撤回已提供信息，请发邮件至 me@nickyam.com。
  2. 如对本政策或您的数据处理有疑问，亦可通过上述邮箱联系我们。

七、政策的变更

我们可能不时更新本政策；更新后继续使用即视为接受修订版本。重大变更将在站点显著位置提示。
